# CI Bill Doctor consumer lab

Repositorio mínimo para validar CI Bill Doctor con pull requests reales.

- `Application CI` produce un historial pequeño y tarifable.
- `CI Bill Doctor Lab` analiza cambios de workflows con permisos de solo
  lectura.
- No se requieren secretos, servicios externos ni dependencias de aplicación.

Este repositorio fue generado desde los activos reproducibles de `lab/` en CI
Bill Doctor. Los escenarios deben aplicarse siempre desde una rama nueva basada
en `main`.
